# Pesquisa

Este módulo guarda o que foi avaliado e tecnicamente não entra no código agora,
com a recomendação de quando e para quê voltar a ele. Não tem código: quem
retoma um item confere de novo o link, a licença e a data, porque a pesquisa
envelhece, e só então o leva a um plano.

- [Bibliotecas](bibliotecas/BIBLIOTECAS.md): bibliotecas JavaScript e
  WebAssembly avaliadas para o núcleo e as ferramentas.

O que já foi adotado ou indicado para uma fatia do plano ativo fica no
[contexto do plano](../../docs/mecanifica/CONTEXTO-FERRAMENTAS-DE-MODELAGEM.md),
e não aqui.
