# Resumo do formato

Raiz: `opcoes` (obrigatório), `plano` (texto ou `{ texto, nivel, medidas, contrato, pecas, referencia, envelope, familia }`), `vista` (`isometrica`, `frontal`, `lateral`, `superior`), `parametros`, `formas` (herdadas pelas opções sem `formas`), `estilos`, `unidades`, `simetrico`, `modulos` (`{ nome: { parametros, formas, ancoras, entradas, pares, substitui } }`, usados por `usa`), `pontos`, `contato`, `curso` (`{ "<mecanismo>": { parametro, de, ate, passos?, rotulo?, formas?, gira?: { eixo, centro, sinal? } } }`, o curso que `--curso` varre e o brief mostra), `explosao` (`{ eixo, fator }` ou, em camadas, `{ eixo?, distancia, ligacoes }`), `legendas` (`colunas`, `lista`), `linhasCentro`, `ocultar`, `ladosPorEscala`, e as opções de desenho que as flags das vistas põem (`corte: { eixo, valor, lado? }`, `enquadrar: { formas, margem? }`, `previa`). Opção: `titulo`, `nota`, `formas`, `parametros`, `pontos`, `contato`, `explosao`, `legendas`, `linhasCentro`, `ocultar`. Forma: `id`, `tipo` (`caixa`, `cilindro`, `anel`, `cone`, `esfera`, `extrusao`, `loft`, `revolucao`, `tubo`, `familia`), `cor` (nome ou `#rrggbb`), `rotulo`, `opacidade`, `oculto`, `estilo`, `unidade`, `lado`, `substitui`, a posição (`centro`, `sobre`, `ponta`, `de`/`para`, `encaixa: { ancora, em, gira }`, `alinha`, `encosta`, `desloca`, `rotacao`) e as medidas do tipo (`caixa`: `largura`, `altura`, `profundidade`, `raio`, `chanfro`, `furos`; `cilindro`: `diametro`, `comprimento`, `eixo`, `achatado`; `anel`: `diametroExterno`, `diametroInterno`, `espessura`, `eixo`; `cone`: `diametro`, `diametroTopo`, `comprimento`, `eixo`; `esfera`: `diametro`; `extrusao`: `perfil` (lista ou `{ gerar }`), `comprimento`, `eixo`; `loft`: `secoes` (`forma`: `retangulo`, `elipse`, `poligono` ou `arredondado` com `cantos` e `segmentosPorCanto`), `eixo`, `casca: { espessura, aberta: "fim" | "inicio" }` (parede oca, a espessura no plano da seção); `revolucao`: `perfil`, `eixo`, `lados`; `tubo`: `caminho`, `diametro`, `raioCurva`; `familia`: `familia` (o id de uma família do registro), `perfil` (opcional), `parametros` (só os ajustes, número, parâmetro ou `"=expressão"`), sem `eixo` nem `de`/`para`). Também uma forma pode ser `{ id, usa: "<componente>", ... }` (com `rotacao`, que gira o componente inteiro em torno da forma principal), `{ id, espelha: { forma, eixo, pos } }` `{ id, ligar: { de, para, tipo: "haste" | "tubo" | "cinta", diametro | largura + espessura } }` ou `{ arranja: { forma, modo, total, ... } }`. Contato: `usar`, `tolerancia`, `penetracao`, `folga`, `pares` (`a`, `b`, `tipo` `atravessa`, `encosta` ou `livre`, `max`, `motivo`), `juntas` (`pecas`, `max`, `motivo`) e `projecao`. O arquivo é validado antes de qualquer leitura: um campo que não existe, um `tipo`, um `eixo` ou uma `cor` inválidos são recusados dizendo o campo, o valor recebido, os válidos e, se o nome é parecido, "quis dizer".
