# Formas novas e componentes

Para um garfo, uma barra dobrada ou um tubo de quadro, escreva `{ "id": "tubo", "tipo": "tubo", "diametro": 24, "raioCurva": 40, "caminho": ["tronco.+y", [-140, 300, 0], [130, 300, 0], "cunha.+y"] }`: cada ponto é um vetor, um ponto nomeado ou uma âncora, o canto vira um arco de seções retas com `raioCurva` (sem ele, uma esfera na junta) e nada de centro, comprimento ou ângulo é calculado. Um ponto ao longo de uma haste é `{ "entre": [A, B], "mm": 90 }` (a 90 mm de A), `{ "entre": [A, B], "mmAntes": 40 }` (a 40 mm de B) ou `{ "entre": [A, B], "t": 0.25 }`, em `centro`, `de`, `para`, `alinha.com` e no `caminho`. `cone` com `diametroTopo` é o tronco, `extrusao` tem o centro no centro da caixa do perfil e `chanfro` na caixa não combina com `raio` nem com `furos`. O tubo, o espelho e o arranjo se combinam (o espelho copia o tubo inteiro). Para dobrar o tubo num ponto sem esfera oculta nem `desloca` de folga, dê nome ao ponto: `{ "nome": "joelho", "ponto": [x, y, z] }` no `caminho` vira a âncora `<tubo>.joelho`, e `{ "ancora": "<id>.<ancora>", "mm": [dx, dy, dz] }` é a âncora deslocada, em qualquer campo que aceita ponto. Toda referência de componente aceita `<instancia>.<parte>` (`rodaFrente.pneu`, inclusive a forma principal).

Antes de modelar uma roda, um garfo, um quadro de caixas ou um mancal à mão, use o componente: `{ "id": "rodaFrente", "usa": "roda", "parametros": { "diametro": "=2*raioRoda" }, "centro": [0, "raioRoda", "=entreEixos/2"], "rotulo": "roda_frente" }` e `{ "id": "garfoE", "usa": "garfo", "de": "rodaFrente.eixo", "para": "quadro.cabecote", "desloca": [-100, 0, 0] }`. As formas saem com o id prefixado (`rodaFrente.pneu`), as âncoras do componente valem como `<instancia>.<ancora>` (`rodaFrente.eixo`, `quadro.cabecote`), o id da instância sozinho é a forma principal (`sobre: "quadro"`), os pares do gate do componente entram sozinhos e o garfo direito é `{ "id": "garfoD", "espelha": { "forma": "garfoE", "eixo": "x" } }`. Os parâmetros, as entradas (`centro`, `de`, `para`, `desloca`...) e as âncoras de cada componente estão em `npm run esboco -- --ajuda componentes` e em `modulos/esboco/componentes/<nome>.json`. Cite as outras partes do componente pelo id com prefixo (`quadro.coluna`, `rodaFrente.disco`) e, num par do gate, declare `atravessa` para a parte que de fato atravessa (o guidão na coroa: `garfoE.coroa`). O `--descrever` marca cada forma como "principal" ou "parte" do componente, e o `--ajustar` só move a principal (pela instância). O exemplo é `modulos/esboco/tests/fixtures/moto-componentes.esboco.json`.

Uma roda 2.0, um cilindro hidráulico, uma dobradiça, um móvel de caixa ou uma superfície aerodinâmica vêm de uma família de `procedural/familias`, e entram no JSON como uma forma: `{ "id": "amortecedor", "tipo": "familia", "familia": "cilindro-hidraulico", "parametros": { "curso": 250, "comprimentoRecolhido": 440 }, "rotacao": [0, 0, -90], "encaixa": { "ancora": "olhal-traseiro", "em": { "ancora": "longarina.-y", "mm": [0, -45, 0] } } }`, e `{ "id": "roda", "tipo": "familia", "familia": "roda-pneu", "perfil": "trem", "parametros": { "diametroPneu": 500 }, "rotacao": [0, 90, 0], "centro": "amortecedor.olhal-dianteiro" }`. As medidas ficam nos `parametros` (só o que difere do `perfil` e dos padrões, na unidade do contrato da família), e a família que não aceita o valor recusa com a restrição e o motivo dela. As portas da família são âncoras da forma (`amortecedor.olhal-traseiro`, `roda.eixo`) e valem em `centro`, `encaixa`, `de`, `para`, `ligar` e na medida `distancia`; `--descrever --forma <id>` lista as portas com o eixo de cada uma no mundo, que é o que se lê para escolher a `rotacao`. O gate de contato usa peças convexas que deixam livres o furo do cubo e o oco da camisa, de modo que o pino no olhal e o eixo no cubo são contato (declare `ponta: true` no eixo cuja ponta termina no ar). Prefira a forma de família ao componente `roda` quando a família existe, e leia `npm run esboco -- --ajuda familia`. O exemplo é `tools/fixtures/esboco-com-familias/perna-do-trem.esboco.json`.
