# Escrever menos JSON

Repetir cor, repetir o lado simétrico e listar pontos de um perfil são o grosso do que se escreve sem pensar. `estilos` na raiz (`{ "metal": { "cor": "#c3c7cc" } }`, com `cor`, `opacidade` e `linhaCentro`) e `estilo: "metal"` na forma dão a aparência comum, e `unidades: { "<unidade>": { "cor": "...", "estilo": "..." } }` dá a cor das formas que declaram `unidade`; a forma manda sobre o estilo e o estilo sobre a unidade. `simetrico: { "eixo": "x", "pos": 0 }` na raiz (ou dentro de uma unidade, que manda sobre a raiz, e `false` a desliga) faz toda forma com `lado: "E"` e id terminado em `E` (ou `lado: "D"` e id em `D`) gerar o espelho de id com a outra letra, sem entrada `espelha`; só vale para a forma que declara `lado`, e a entrada explícita de mesmo id prevalece. O `perfil` de `extrusao`, `revolucao` e de uma seção de `loft` pode ser uma função, com parâmetros e expressões nos argumentos: `{ "gerar": "estrela", "n": 5, "rin": 62, "rout": 207, "semi": 11 }` (n raios, `semi` é a largura angular da ponta em graus, o primeiro raio para +v), `{ "gerar": "arco", "raioExterno": 325, "raioInterno": 312, "angulo": 34, "passos": 8 }` (faixa de coroa de -angulo a +angulo em torno de +v), `{ "gerar": "circulo", "raio": 40, "lados": 24 }` e `{ "gerar": "polar", "pontos": [[angulo, raio], ...] }`, todos com o centro do círculo na origem do plano do perfil. Para mudar um esboço pronto não regrave o JSON nem escreva um script: `npm run esboco -- --editar <arquivo> <forma>.<campo>=<valor> ...` muda vários campos de uma vez (o valor é JSON, número, texto ou `"=expressão"`; também `<forma>.<campo>.<sub>` e `centro[1]`; `null` retira o campo), `--remover <forma>` tira formas e `--adicionar '<json-da-forma>'` acrescenta, preservando recuo, parâmetros e expressões; o esboço editado passa pelo esquema e pela leitura antes de gravar (recusado, o arquivo fica como estava e a mensagem diz o campo e o válido) e a leitura padrão das divergências sai logo depois. Um exemplo pequeno de tudo isso é `modulos/esboco/tests/fixtures/estilos-perfis.esboco.json`.
