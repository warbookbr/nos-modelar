# Variantes, simetria e repetição

Quando a pessoa pede duas atitudes do mesmo objeto (alto e baixo, aberto e fechado), escreva a lista de formas uma vez, na raiz, e faça cada opção só com `titulo`, `nota` e `parametros`: `{ "parametros": { "alturaColuna": 240, "larguraGuidao": 760 }, "formas": [ ... ], "opcoes": [ { "titulo": "A" }, { "titulo": "B", "parametros": { "alturaColuna": 180, "larguraGuidao": 540 } } ] }`. O parâmetro é um número, o nome de outro parâmetro ou `"=expressão"` com `+ - * /` e parênteses, e vale em qualquer campo numérico (`"altura": "alturaColuna"`, `"centro": [0, "raioRoda", "=-entreEixos/2"]`). A opção sobrepõe a raiz nome a nome, e o que depende do parâmetro se recalcula sozinho. Não há seno nem cosseno: para uma haste inclinada use `de`/`para`, e para pôr peças numa circunferência use `arranja` radial. Parâmetro inexistente, ciclo e expressão inválida são recusados com o campo, a forma e os parâmetros válidos. A leitura `--descrever` imprime `parâmetros:` por opção com os valores resolvidos, e o manifesto da `--analise` os guarda em `parametros`.

Para a peça simétrica escreva só a metade: `{ "id": "garfoD", "espelha": { "forma": "garfoE", "eixo": "x", "pos": 0 } }` gera o sólido refletido da fonte (que pode vir depois), herda `cor`, só leva `rotulo` se você o declarar, e aceita apenas `id`, `cor`, `rotulo`, `oculto`, `opacidade`, `unidade` (sem ela vale a da fonte) e `desloca`. Com o gate ligado, o par do espelho herda o `atravessa`, o `livre` ou o `encosta` do original com o mesmo `motivo` e `max`, então declare `guidao ↔ garfoE` uma vez e não escreva `guidao ↔ garfoD`; o par entre o original e a cópia (`garfoE ↔ garfoD`) continua cobrado como qualquer outro. Para repetir uma peça, escreva na lista uma entrada `{ "arranja": { "forma": "parafuso", "modo": "linear", "total": 4, "passo": [0, 0, 60] } }` ou `{ "arranja": { "forma": "parafuso", "modo": "radial", "total": 6, "eixo": "y", "centro": "flange.centro", "graus": 360 } }`: `total` conta a fonte, as cópias são `parafuso1` a `parafuso5` (ou os `nomes` que você der), sem rótulo, e entram no gate e no `--descrever` como qualquer forma. O exemplo completo é `modulos/esboco/tests/fixtures/moto-parametros.esboco.json`.
