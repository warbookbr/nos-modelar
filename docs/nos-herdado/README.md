# Herança do NÓS

Esta pasta guarda documentos do projeto de onde a Mecanifica foi clonada. Eles
descrevem a Oficina humana, o Playground e a aplicação jogável — coisas que
**não existem mais neste repositório**. Chamava-se `docs/historico/`, e o nome
confundia com o histórico da própria Mecanifica, que é outra coisa e fica em
[`../mecanifica/historico/README.md`](../mecanifica/historico/README.md): lá
estão os relatórios e experimentos deste produto.

A distinção importa porque as duas zonas têm o mesmo peso — nenhuma governa
trabalho novo — mas assuntos diferentes. Aqui está o que o NÓS decidiu; lá está
o que a Mecanifica mediu.

| Arquivo | O que guarda |
|---|---|
| [`playground.md`](playground.md) | o épico da criação por IA na Oficina, com as regras de formato salvo que o núcleo procedural ainda cita |
| [`TETO.md`](TETO.md) | a medição de onde o vocabulário de operações parava, feita com uma criação de verdade |
| [`oficina-projeto.md`](oficina-projeto.md) | o racional de design das funções da Oficina e a migração para WebGL 2 |
| [`oficina-contrato.md`](oficina-contrato.md) | a gramática procedural da Oficina, 1.025 linhas, ainda consumida por `npm run criar` |
| [`oficina-referencia.md`](oficina-referencia.md) | o aviso de que a interface humana, a aba de som e o servidor antigo não existem mais |

Estes arquivos continuam sendo citados por comentário de código — o `nucleo.js`
aponta para a regra 4 do `playground.md` como fonte do formato salvo, e o
gabarito do banco de ensaio aponta para o P5. Por isso a pasta foi renomeada e
não removida: o endereço mudou, a lição continua valendo.
