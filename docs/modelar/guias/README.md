# Guias

Guias de como fazer uma tarefa de modelagem ou de autoria que ainda citam plano, histórico ou documento de desenvolvimento: carroceria, veículo, chassi e lataria, o fluxo de modelagem, a bancada e a leitura por tarefa.

Não moram aqui:

- os guias de uso que uma skill aplica e que só citam documento de uso, que ficam em `../usar/`, pasta com regra conferida por `npm run docs:estrutura:check`;
- formato, contrato e regra de consulta, que ficam em `../contratos/`;
- visão e o porquê de uma escolha, que ficam em `../decisoes/`.

Um guia daqui passa para `../usar/` quando deixa de citar documento de fora dela e uma skill o aplica. A entrada do conjunto é `../INDEX.md`.
