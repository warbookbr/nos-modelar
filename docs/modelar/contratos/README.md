# Contratos

Formatos, contratos e regras de consulta do Modelar: o que um arquivo, um serviço
ou uma operação declara, aceita e recusa, escrito para quem precisa conferir um
detalhe e não para quem vai executar uma tarefa do começo ao fim.

Não moram aqui:

- guias de como fazer uma tarefa, que ficam em `../usar/`;
- visão, critério e o porquê de uma escolha, que ficam em `../decisoes/`;
- pesquisa, análise e levantamento com data, que ficam em `../pesquisas/`;
- plano, que fica em `../planos/`.

A entrada do conjunto é `../INDEX.md`.
