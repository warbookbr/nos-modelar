# Oficina — aviso de compatibilidade

A interface humana descrita na versão anterior deste documento foi removida.
Não existe `oficina.html`, aba de som nem o antigo servidor de desenvolvimento neste
repositório. A aplicação publicada é `bancada.html`, voltada à inspeção das
peças e das receitas atuais.

Para o contrato procedural ainda consumido por `npm run criar`, consulte
[`oficina-contrato.md`](oficina-contrato.md): a tabela e as seções “Pose de
criação”, “Encostar” e “Cópias nomeadas” são a referência operacional neutra.
Skills de agentes só complementam esse contrato; não são sua fonte exclusiva.
Para o estado vigente, fontes de verdade e comandos, consulte
[`docs/mecanifica/INDEX.md`](../mecanifica/INDEX.md).
