# Sonda N5 — busca sobre liberdade residual

Prova isolada de C3. N4 mantém as três restrições; N5 expõe somente
`bojoRelativo`, de 0,08 a 0,28, em uma seção sintética. O objetivo medido é a
sagita central de 41,6 mm. A busca enumerativa determinística só escolhe entre
candidatos que permanecem C1-regulares e satisfazem todas as restrições.

O alvo é sintético e existe para testar o mecanismo de busca, não para definir
o estilo de uma carroceria. As seis evidências do vencedor precisam de
inspeção individual, em tamanho nativo, e são ligadas ao manifesto por SHA-256.
