# Prova privada R2 — cage autoral direta

Esta é uma prova nova; não reutiliza receitas ou geometria de
`rascunhos-defeituosos/`. A primeira rodada só fixa o envelope, o quadro de
captura e as unidades semânticas da futura cage. Não há arco, farol, vidro ou
recorte nesta etapa.

A cage é escrita explicitamente em quadriláteros e suas alterações usam loops
nomeados. Capô, base do para-brisa, teto, queda traseira, ombro e cintura são
controles distintos; o ombro carrega vinco de um nível. Seções transversais
entram apenas como medição posterior, nunca como gerador de vértices.
